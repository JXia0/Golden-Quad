## 02_Interlude_Firsts：自己到学校

公交持续运行，玩家观察三个站点，在合适的时候按 F 请求下一站停车；再按 F 可以取消。提前下车就向右步行，坐过站就向左走回来，在学校下车则少走一段。没有按铃不会自动完成，也没有错过站就失败重开的惩罚。

到学校后按住 E 举起手，松开把手举出去，再按 F 进入舞台。下车站点被记录，路线和途中看到的回忆会不同。幼儿园带走的玩具或留下玩具后携带的书包也会显示在这一段。

已接入现有图片：公交、朋友家过夜、父母疲惫、课堂举手。后两种下车路线分别显现不同的回忆；不是要求每次都看完所有分支图片。

## 04_Interlude_Growing：修补与去向

A/D 选择纸片，按住 E 拿起，用 A/D 移动，松开在对应浅色轮廓上放下。未对齐可以重新拿起，不会清空已修好的部分。三片拼好后，拿起整页放到左边寄回家里，或放到右边留进自己的笔记。决定后按 F 去研究室。

寄回去会收到关于风与灯的图示提示；留在笔记中会保留关于工具复用的提示。研究室按 H 能回看对应信息，两种选择都保留全部通关方法。

已接入“被拒绝”和“争吵”两张现有蒙太奇图。拼纸目前复用现有笔记图片，正式呈现可替换为一张可分三片的稿纸；不要求美术重做背景。

## 给美术与呈现的接口

`InterludeController` 负责两段交互。`Firsts.Phase`：Riding / Walking / RaisingHand / Ready；`Firsts.Position` 和 `ExitStop`：车、人的位置和下车点。`Repair.Pieces`、`Placed`、`Selected`、`Holding`、`RepairedCount`、`LetterPosition`、`Destination`：纸片及去向状态。`MomentChanged` 提供当前图片对应的资源名。

`JourneyChoices.BusExitStop` 与 `RepairedNoteDestination` 保存结果。后者取值 home / notebook。`ResearchGuide.Step`、`GoalText`、`SituationText`、`FocusText`、`HelpVisible` 提供当前引导状态。

功能 UI 使用独立 Canvas，位于原有淡入淡出层下方，可被正式呈现替换。保留目标、操作提示及明确的状态反馈，不要在替代品尚未接入时隐藏。既有图片只进行运行时显示和纸片分区，没有改写图片文件。

场景构建列表、幼儿园和舞台的出口已恢复两段过渡。旧场景在运行时也会纠正旧出口配置。场景构建器的七场景顺序同步修正，但本次没有执行重建器。
