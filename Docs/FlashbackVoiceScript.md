# Flashback 配音稿

成年后的主角回望这一程。约 30 秒；轻声、自然地讲，像说给身边的人听。不要刻意哭腔，停顿比强调更重要。

## 录音正文

小时候，我走得很慢。
你们总会回头，等我。

后来，我也学会了等一等。
等一个声音，等一次尝试，
等一只手，慢慢松开。

你往前走吧。

我会带着你们给我的勇气，
继续走下去。

## 建议节奏与画面

| 时间 | 台词 | 画面可对应 |
| --- | --- | --- |
| 0–6 秒 | 小时候，我走得很慢。你们总会回头，等我。 | 父母牵手，松手后在门边等候。 |
| 6–11 秒 | 后来，我也学会了等一等。 | 孩子试着走向玩具，主角在旁边停下。 |
| 11–20 秒 | 等一个声音，等一次尝试，等一只手，慢慢松开。 | 观众接唱、小人尝试、松开的手。画面之间留一点呼吸。 |
| 20–23 秒 | 你往前走吧。 | 年轻人朝门里走去。说完停一下。 |
| 23–30 秒 | 我会带着你们给我的勇气，继续走下去。 | 主角最后一步，回忆渐暗；短片结束后进入已交付的结束图。 |

时间只是剪辑参考，录音以自然语速为准。每段之间留空，不必硬卡字速。

## 交付

先录一条连续干声即可，首尾各留 1–2 秒安静。建议 WAV、48 kHz，文件名 `vo_flashback.wav`；先不加混响和背景音乐，方便与短片一起混音。

程序预留位置：FinalWalk 最后一步之后 → flashback → 结束图。最终视频建议 1920×1080、16:9；准确导入位置会随播放接入说明一起提供。
