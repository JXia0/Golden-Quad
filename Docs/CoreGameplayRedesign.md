# 《放开我的手》核心玩法重构

> 2026-09-05 更新：作者确认最终方向为“成长必须告别”。当前可玩实现、改动范围和交稿前安排以 [GGJEmotionalPlayable.md](GGJEmotionalPlayable.md) 为准；下文保留早期主题设计，其中任务链、研究定稿和结尾已有调整。

## 设计目标

玩家不通过阅读得知“成长意味着放手”，而是在安全与前进之间亲自作出动作：

> 按住以维持连接，松开以继续前进。

同一个动作在三个年龄阶段逐渐改变对象：

1. 幼儿抓住父母。
2. 少年稳住自己。
3. 成人抓住一个尚未确定的判断。
4. 结局成为别人可以抓住的人，并再次主动放手。

如果关闭全部旁白，只保留角色、灯光、声音和规则，玩家仍应能够描述出这条变化。

## 玩家操作

| 输入 | 行为 |
|---|---|
| `A/D` 或方向键 | 行走 |
| `Space` | 小幅跳跃，只用于越过低矮场景物件 |
| 按住 `E` | 抓住附近的手、物体或自己的胸口 |
| 松开 `E` | 放手、放下物体或释放一口气 |
| `R` | 回到当前段落起点 |

游戏不再使用“靠近后按一次 E 完成任务”作为主要玩法。关键行为都要求玩家维持按住，再亲自决定何时松开。

## 核心状态

### 1. 未连接

- 玩家可以自由移动。
- 环境中的恐惧表现逐渐增强：轻微晃动、暗角、远处影子靠近、心跳加快。
- 没有传统血条；胸口光的强弱表示当前稳定程度。

### 2. 抓住外部支点

- 玩家与目标之间出现一条柔和光线。
- 环境恢复稳定，心跳减弱。
- 玩家只能在支点允许的距离内移动。
- 光线从松弛、拉直逐渐变成偏白，不使用红色警告或数字 UI。
- 达到最大距离时角色停下，连接不会自动断开。必须由玩家松开 `E`。

### 3. 稳住自己

- 附近没有可抓目标时，按住 `E` 会让角色把手放在胸口。
- 玩家暂时不能移动。
- 胸口光逐渐充满，舞台或环境恢复稳定。
- 松开 `E` 后获得几秒稳定移动时间；时间结束后可以再次停下呼吸。

### 4. 抓住物体

- 资料、玩具等物体通过光线连接到手中，不打开背包 UI。
- 物体在角色身侧浮动。
- 松手时物体落下；位于正确接收区域时自动吸附。
- 同一时间只能抓住一个目标。

## 连接的实现规则

- 不制作绳索物理。
- 使用 `LineRenderer` 绘制光线。
- 使用角色与目标之间的距离计算张力。
- 最大距离只限制玩家水平移动，不模拟摆动、弹性碰撞或复杂关节。
- 所有响应使用颜色、音量和简单插值，避免高计算量。

连接包含三个视觉阶段：

| 距离 | 光线 | 环境 | 含义 |
|---|---|---|---|
| 近 | 温暖、松弛 | 完全稳定 | 我还在你身边 |
| 中 | 逐渐拉直 | 轻微暗下 | 我正在尝试走远 |
| 极限 | 变细、接近白色 | 门或前方目标更明亮 | 必须作出放手决定 |

## 第一幕：幼儿园

目标时长：4–5 分钟。

### 段落一：学会被牵着走

- 开场时玩家已经按住父母的手，系统不先弹出教程窗口。
- 玩家向右移动，父母保持在身后约 1.2 units。
- 玩家走得太快时，父母会轻轻停下，光线拉直，主角速度下降。
- 父母停下后等待玩家回到舒适距离，再继续一起走。

这一段让玩家先体验连接的好处和限制。

### 段落二：门无法带着两个人通过

- 幼儿园门框是一个 `HandGate`。
- 主角可以走到门内，但父母停在门外。
- 继续按住 `E` 时，光线达到极限，角色不能再前进。
- 门内玩具声、暖色脚印和另一个孩子的哭声吸引玩家向前。
- 门上不显示“按 E 放手”。只在光线达到极限时出现一次松手图标。
- 玩家松开 `E` 后，门完全打开，主角可以进入。
- 玩家在跨过第二道门槛前仍能回去重新牵手，允许玩家试探。

### 段落三：独自行走

- 走廊中的桌椅尺寸比正常大约 30%，形成孩子视角。
- 未连接时，远处其他孩子表现为模糊影子。
- 玩家经过柜子、座位和玩具，但它们不再组成三个任务。
- 这些物件只通过摆放讲述主角正在寻找自己的位置：空柜子、写着名字的椅背、掉在路中的玩具。
- 玩家停下时可以听见门外父母的脚步或衣物声，转身仍能看到父母的光。

### 段落四：牵住另一个孩子

- 哭泣的孩子蜷缩在教室入口旁，周围影子最浓。
- 玩家靠近并按住 `E`，光线第一次从主角延伸到别人。
- 哭泣声逐渐减弱，孩子站起来。
- 玩家需要继续按住 `E`，慢慢带孩子走到老师旁边。
- 玩家走得太快时，孩子不会被拖行，而是停下来。玩家必须退回，让光线重新松弛。
- 到达老师旁边后，玩家松开 `E`。孩子独自走进教室。
- 主角胸口保留一小点父母颜色的光。

第一幕的可玩情绪变化：接受保护 → 主动离开 → 成为短暂的保护者。

## 第二幕：舞台

目标时长：4 分钟。

### 段落一：后台最后一次外部支撑

- 玩家可以在幕布前按住父母的手或肩膀。
- 幕布是第二个 `HandGate`，父母不会穿过。
- 玩家松手后进入舞台，外部支点从本幕移除。

### 段落二：呼吸形成移动节奏

- 进入舞台后，观众首先表现为巨大眼睛。
- 玩家移动时舞台轻微倾斜，聚光灯缓慢漂移。
- 按住 `E` 后主角把手放在胸口，不能移动。
- 约 1.2 秒后胸口光充满，舞台变稳，观众短暂恢复成人形。
- 玩家松开 `E` 后可以在约 3 秒的稳定时间中移动。
- 稳定时间结束不会死亡，玩家只需再次停下呼吸。

玩家自然形成：停下 → 吸气 → 松开 → 前进。

### 段落三：用空间作出表演选择

- 第二个站位分成两条真实路线，不显示文字选项。
- 后方站位距离近，灯光柔和，观众较暗。
- 前方站位距离远，需要多进行一次呼吸，玩家更接近观众。
- 两条路线都能完成演出，不评价勇敢或胆小。
- 玩家走入哪个站位，最终记忆长廊就保留哪一种构图。

### 段落四：松开时说出台词

- 最终站位出现一个随着呼吸扩大的光圈。
- 玩家按住 `E` 吸气，光圈逐渐与聚光灯重合。
- 不要求精确节奏，不设置失败判定。
- 玩家松开 `E` 的瞬间，主角说出：“我准备好了。”
- 声音可以发抖，但舞台不会判定失败。
- 观众眼睛变成人形，掌声进入，幕布打开出口。

第二幕的可玩情绪变化：依靠别人稳定 → 学会自己停下来 → 带着颤抖继续行动。

## 第三幕：研究与汇报

目标时长：5–6 分钟。

### 段落一：导师只把问题交给玩家

- 导师将一张没有答案的问题卡放在桌上。
- 玩家需要按住 `E` 抓起问题，亲自带入研究空间。
- 导师留在门外，不提供下一步箭头。

### 段落二：把问题固定在工作板

- 工作板中央有一个空白位置。
- 玩家松开问题卡时，如果位于工作板范围，它会被钉住。
- 问题被钉住后，两侧各亮起一份不同方向的证据。

### 段落三：选择证据

- 两份证据使用明显不同的物体构图，例如照片记录和数据图表。
- 玩家只能抓起并提交其中一份。
- 第一份证据被固定后，另一份不会消失，只会退到阴影中。
- 游戏不显示“正确”或“错误”。
- 最终长廊会保留未被选择的证据轮廓，让玩家知道其他可能性仍然存在。

### 段落四：提交一个不完全确定的结论

- 证据固定后，结论卡出现，但边缘不断被怀疑影子拉扯。
- 玩家按住 `E` 抓住结论，向工作板移动。
- 影子不会攻击角色，只会让结论卡晃动并增加纸张噪声。
- 玩家到达工作板后松开 `E`，代表提交自己的判断。
- 怀疑影子缩小成报告边缘的注释，没有被消灭。
- 会议室门在报告完成后打开。

第三幕的可玩情绪变化：等待答案 → 选择证据 → 接受其他可能 → 为自己的判断负责。

## 最终长廊

目标时长：2 分钟。

- 不显示回忆字幕。
- 玩家经过三组已经玩过的 GameObject：幼儿园门、舞台站位、研究工作板。
- 玩家之前的空间选择会改变这些物件的位置和光线。
- 年龄转换通过经过门框、幕布和书架完成。
- 角色胸口的光从父母的暖色，逐渐变成自己的颜色。

长廊尽头，一个年轻人站在门前并自然伸手。

- 玩家按住 `E`，主角牵住年轻人。
- 年轻人的呼吸和身体逐渐稳定。
- 只要玩家继续按着，年轻人就留在门外。
- 玩家松开 `E` 后，年轻人独自进入门内。
- 主角不跟进去，只留在原地。
- 门内白光亮起，画面切黑。

结局不需要解释“成为别人回头时仍站在那里的人”。玩家刚刚亲自完成了这个动作。

## GameObject 清单

| GameObject/组件 | 作用 | 三幕复用方式 |
|---|---|---|
| `HoldTarget` | 可被按住的目标 | 父母、孩子、资料、年轻人 |
| `HandConnection` | 管理距离和当前连接状态 | 所有抓住/放开行为 |
| `LineRenderer`（由 `HandConnection` 管理） | 绘制光线和张力变化 | 所有连接对象 |
| `ReleaseGate` | 检查玩家是否主动放开后越过门槛 | 幼儿园门 |
| `SelfAnchorCue` | 没有外部目标时稳定自己 | 舞台呼吸点 |
| `HoldSocket` | 接收松开的物体 | 老师位置、工作板、报告位置 |
| `EmotionalEnvironment` | 根据连接状态调整灯光、晃动和音频 | 三个主要场景 |
| `MemoryChoiceEcho` | 显示玩家实际选择过的空间物件 | 最终长廊 |

核心运行逻辑控制在这些组件内，不制作复杂物理、敌人 AI、物品栏或对话树。

## 文字限制

- 开场最多两句旁白。
- 每幕结束最多一句旁白。
- 教学只使用手掌图标、按键图标和光线变化。
- 场景中允许出现“问题”“证据”“结论”等物件标签，但不写解释段落。
- 所有旁白都应在关闭后不影响玩家理解目标。

## 灰盒验收标准

当前五个正式场景已使用同一套连接系统完成灰盒搭建。

测试玩家在没有背景美术、没有旁白的情况下，应能回答：

1. 牵着父母时是否感到安全但受到限制？
2. 是否明白自己必须主动松开，而不是等剧情替自己放手？
3. 独自行走时是否仍能通过父母的远处光线感到支持？
4. 牵住哭泣孩子后，是否意识到自己的角色发生了变化？
5. 带孩子移动时，是否自然放慢速度而不是拖着他走？

至少四项成立后，再将同一系统扩展到舞台和研究场景。
