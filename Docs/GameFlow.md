# 《放开我的手》最终游戏流程

## 游戏规格

- 类型：Universal 2D 横版叙事互动游戏
- 目标时长：12–16 分钟
- 操作：`A/D` 或方向键移动，`Space` 跳跃，按住 `E` 抓住/呼吸，松开 `E` 放手/提交，`R` 回到检查点
- 核心规则：**按住维持连接，松开才能继续前进**
- 失败：没有死亡、战斗、计时或 Game Over

正式 Build 只包含五个场景。两段成长蒙太奇已从 Build 移除，人生跨度改由最终长廊中的 GameObject 回放承担。

## 00_Prologue — 会议室门外（约 30 秒）

成年主角站在会议室门外。玩家走到门前触碰门把手，短旁白建立“长大并非只发生一次”，随后直接进入幼儿园回忆。

## 01_Kindergarten — 接受保护，再成为保护者（4–5 分钟）

1. 按住 `E` 牵住父母。连接光线随距离变细，父母跟随主角。
2. 父母停在幼儿园门外；只要玩家继续按住，主角就无法跨过最大距离。
3. 玩家亲自松开 `E`，跨过门槛。陌生影子和环境晃动随失去连接增强。
4. 玩家越过放大的椅子和积木，找到哭泣的孩子。
5. 按住 `E` 牵住孩子，放慢速度把他带到老师身边。
6. 在老师旁松开 `E`。孩子留下，出口打开。

这一幕的动作变化是：被牵着走 → 主动放手 → 牵住别人 → 再次放手。

## 03_Stage — 用呼吸创造行动窗口（约 4 分钟）

1. 后台仍可按住父母的手；幕布限制连接距离，玩家必须放手进入舞台。
2. 观众以眼睛出现，舞台与画面轻微晃动。
3. 在第一束聚光灯中按住 `E`。主角停止移动并把手放在胸口；约 1.2 秒后稳定。
4. 松开 `E` 获得约 3 秒稳定移动时间，形成“停下 → 呼吸 → 松开 → 前进”的节奏。
5. 玩家用空间作出表演选择：走地面的稳妥站位，或跳上更靠近观众的前方站位。
6. 最后一束光中再次按住 `E`，光充满后松开。松开的瞬间主角说出“我准备好了”，眼睛变淡并响起掌声。

最终台词不再是一次普通按键检查；必须在最后站位完整蓄满一次呼吸并主动松开。

## 05_Research — 抓住一个判断并提交（5–6 分钟）

1. 按住 `E` 抓起问题卡，带到问题板前，松手固定。
2. 两种证据同时出现：照片记录与数据图表。玩家只能选择并提交其中一份，另一份退入阴影。
3. 证据确定后，结论卡可以被抓住。怀疑影子使环境变暗、晃动并增强心跳。
4. 玩家带着结论继续前进，在结论板旁松手提交。怀疑缩小，报告完成，会议室门打开。

资料没有背包 UI 或正确答案判定。物体始终显示在角色手边，松手本身就是选择与承担。

## 06_FinalWalk — 把手交给下一个人（约 2 分钟）

1. 玩家从左向右走过幼儿园、舞台和研究空间的 GameObject 回声。
2. 经过门框、幕布和研究板时，角色从幼儿变为少年，再变为成人。
3. 舞台展示玩家选择过的实际站位；研究板展示玩家提交过的照片或数据证据。
4. 长廊尽头的年轻汇报者伸手。玩家按住 `E`，连接光线逐渐稳定他。
5. 玩家继续按住时，两人都会留在门外；玩家松开后，年轻人独自走向门内，画面切黑。

结尾只保留一句“我会在这里。”和标题。情绪结论由玩家刚刚完成的动作表达。

## 交付与验收

- 每个主要场景都有可独立理解的物理目标、视觉反馈和声音反馈。
- 关闭旁白后，牵手距离、环境不稳定、站位、资料插槽和门仍能指引流程。
- Build Settings 顺序为：`00_Prologue` → `01_Kindergarten` → `03_Stage` → `05_Research` → `06_FinalWalk`。
- 美术放入 `Assets/Art/Final`，音频放入 `Assets/Audio/Final`，然后执行 `Tools > Let Go > Apply Final Art By Filename`。
- 不制作战斗、背包、对话树、复杂绳索物理、敌人 AI 或分支结局。
