# 《放开我的手》完整游戏流程

## 游戏规格

- 类型：2D 横版叙事互动游戏
- 目标时长：15–20 分钟
- 操作：`A/D` 或方向键移动，`Space` 跳跃，`E` 互动/牵手/呼吸，`R` 返回检查点
- 主循环：站在门前 → 获得支持 → 放开手 → 完成三至四个互动 → 带走一部分光
- 失败：勇气耗尽时立即回到当前检查点，不出现死亡或 Game Over

## 场景顺序

### 00_Prologue — 会议室门外（约 30 秒）

成年主角拿着独立完成的研究报告，站在会议室门外。玩家可以走到门前，按 `E` 触碰门把手。

旁白：

> 小时候，我以为长大，是某一天突然发生的事。  
> 像生日，像毕业，像门框上突然高出的一条线。

触碰门后进入第一段回忆。

### 01_Kindergarten — 幼儿园的门（约 4–5 分钟）

1. 玩家牵着父母的手向右移动，发光线限制最大距离。
2. 到达教室门口，按 `E` 放手，勇气开始缓慢下降。
3. 探索教室并完成三组“寻找 → 拾取 → 交付”互动：
   - 找到书包，把它带到自己的柜子。
   - 找到名字卡，把它带到自己的座位。
   - 找到掉落的玩具，把它递给哭泣的孩子。
4. 玩家一次只能携带一件物品，可以自由决定先完成哪一组。
5. 全家画、积木城堡和窗户可以额外检查，不计入必要目标。
6. 回头仍能看见留在门口的父母。
7. 主角获得第一点光，进入教室。

玩家可以在勇气不足时返回父母身边恢复。最终记忆长廊会显示玩家最先完成的幼儿园互动。

关键旁白：

> 你没有跟进来。  
> 但当我回头时，你还在那里。

### 02_Interlude_Firsts — 更多第一次（约 20 秒）

依次显示五张剪影字幕：独自在朋友家过夜、课堂举手、独自坐公交、发现父母也会疲惫，以及总结旁白。该场景自动进入下一幕。

### 03_Stage — 舞台的幕布（约 3–4 分钟）

1. 主角在后台得到父母的陪伴，但不再牵手。
2. 穿过幕布后勇气开始下降；按住 `E` 可以稳定呼吸。
3. 完成三个舞台互动：
   - 走进第一束聚光灯，按住 `E` 完整稳定一次呼吸。
   - 在“稳稳完成”和“主动向前一步”之间选择一种表演方式。
   - 面对观众，按住 `E` 说出“我……准备好了”。
4. 观众的眼睛恢复为普通剪影，响起掌声。
5. 主角获得第二部分光并走下舞台。

舞台道具和观众席可以额外检查，提供角色内心旁白。

### 04_Interlude_Growing — 长大以后（约 20 秒）

依次显示被拒绝、与朋友争吵、离开家、做错决定、第一次道歉，以及总结旁白。

### 05_Research — 没有标准答案（约 5–6 分钟）

导师把资料交给主角，并明确表示答案尚不存在。

资料分散在研究空间中。玩家一次只能携带一份资料，需要将它送到中央工作板对应的槽位：

1. **问题**：接受自己可能理解错误。
2. **证据**：接受结果可能不完美。
3. **结论**：接受自己可能无法回答所有问题。

三部分最终在画面中构成“问题 → 证据 → 结论”。玩家可以自由选择收集顺序，错误槽位会给出提示而不惩罚。废弃草稿和导师便签可以额外检查。最终记忆长廊会保留玩家最先选择的研究切入点。

三份资料全部归位后，玩家还需要在工作台前按住 `E` 整理最终报告。主角接受答案并不完整，第四个目标完成后会议室门才会打开。

### 06_FinalWalk — 记忆长廊（约 60–90 秒）

该场景没有失败、谜题或计时。玩家可以向右前进、停留或回头。

1. 主角以幼儿形态经过幼儿园，父母留在原地。
2. 穿过门框后成为少年，经过空舞台与聚光灯。
3. 舞台灯变成书桌灯，主角成为成人，经过问题、证据、结论和已经被接受的怀疑。
4. 三个阶段分别显示玩家在幼儿园、舞台和研究空间作出的选择。
5. 主角抵达一扇没有标签的门。
6. 提示“按 E 寻找一只手”；身旁没有人回应。
7. 主角将手放回胸口，握住门把手。
8. 门打开一条白色缝隙，在显示门后内容前切黑。

最终字幕：

> 《放开我的手》  
> 每一次放手，都是第一次长大。

## 统一制作限制

- 每幕只包含三至四个主要互动。
- 不制作战斗、背包、对话树、分支结局或复杂绳索物理。
- 所有场景复用同一个玩家控制、勇气、互动、字幕、检查点和转场系统。
- 美术替换只修改 SpriteRenderer、背景和动画，不改变关卡逻辑。
- 必要互动使用拾取、交付、长按和选择四种反馈；观察点只补充叙事，不阻塞流程。
