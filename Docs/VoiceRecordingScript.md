# 《Let Go》完整配音录制稿

这次需要录两条：开场旁白、结尾 flashback。两条都由成年后的主角讲述，用你自然的声音即可，不必分别扮演孩子、少年和老人。

语气是把一件记了很久的事，轻轻说给身边的人听。开场带一点回想；结尾有不舍，但最后一句要能往前走。不要播音腔，也不用刻意哭出来。

## 01｜开场旁白

文件名：**vo_prologue.wav**。预计 12–16 秒，以自然朗读为准。

出场位置：玩家按下 Start，开始界面退去之后。以下正文与目前游戏的开场文字一致。

> 小时候，我以为长大，是某一天突然发生的事。
>
> 像生日，像毕业，像门框上突然高出的一条线。

读法：“小时候”后稍停；第一句读完，留一次自然呼吸。第二句里的三个“像”是想到三个具体的画面，不用一句比一句用力。“一条线”轻轻收住。

## 02｜结尾 flashback

文件名：**vo_flashback.wav**。短片目标约 30 秒；这是前一份 flashback 稿的同一版正文，不用重复录两份。

出场顺序：**FinalWalk 走完 → flashback 短片 → 已交付的结束图**。最后一句留在短片结尾，结束图出现后给画面和音乐留白。

> 小时候，我走得很慢。
> 你们总会回头，等我。
>
> 后来，我也学会了等一等。
> 等一个声音，等一次尝试，
> 等一只手，慢慢松开。
>
> 你往前走吧。
>
> 我会带着你们给我的勇气，
> 继续走下去。

| 参考时间 | 录音正文 | 语气与剪辑参考 |
| --- | --- | --- |
| 0–6 秒 | 小时候，我走得很慢。你们总会回头，等我。 | 想到父母回过头等自己，可以带一点很淡的笑。 |
| 6–11 秒 | 后来，我也学会了等一等。 | 语气自然转到现在，留出一次呼吸。 |
| 11–20 秒 | 等一个声音，等一次尝试，等一只手，慢慢松开。 | 对应接唱、尝试和松手。“慢慢松开”放轻。 |
| 20–23 秒 | 你往前走吧。 | 对走向门的年轻人说。温柔、明确，说完停一下。 |
| 23–30 秒 | 我会带着你们给我的勇气，继续走下去。 | 回到对父母的心里话。最后一句平稳收住，不要喊出宣言感。 |

表格时间是朗读参考。已交付的 flashback 录音实长约 27.477 秒，影片为 30 秒；程序在影片实际播放到 0.5 秒时启动录音，保留录音自带的开头留白与影片收尾，不必重新赶字录制。

## 录音交付

每条单独一个文件，首尾各留 1–2 秒安静。建议 WAV、48 kHz、单声道；24 bit 优先，设备只支持 16 bit 也可以。保持同一麦克风、距离和录音环境，避免喷麦和音量爆掉。

先交干声，不加背景音乐、混响或强降噪。无需为了处理音效耽误录制。

- 开场：`Assets/Resources/Voice/vo_prologue.wav`，由程序在 Start 后播放。
- 短片旁白：`Assets/Audio/Voice/vo_flashback.wav`，通过 `SceneAudioLibrary.flashbackVoice` 引用，由程序在影片实际播放至 0.5 秒时叠加一次，音量为 1。原录音保持不变。
- 已交付短片：`Assets/Resources/Ending/flashback.mp4`，30 秒、1280×720、16:9。用户确认影片尚未混入旁白，因此保留其现有音乐并由程序叠加上述录音；旁白期间影片音乐平滑降至 30%，结束后恢复。现在不需要再把录音混入 MP4。

两条录音与短片均已交付。若以后缺少开场录音，仍保留文字；若缺少短片，结尾直接进入结束图，不让玩家等待空白的 30 秒。将来若替换为已经混入同一旁白的影片，应同时清空 `SceneAudioLibrary.flashbackVoice`，避免重复配音。
