# 学会你的习惯

研究室保留箱子、折叠板、灯、玩具和牵手的原有解法。新玩法改变的是小人的办法：玩家亲自示范，小人从真实动作中学会跨缺口、停顿，以及在暗处前安定自己或等待帮助。

- 开门并拉开内侧门闩后，在小人起点附近按 **T** 开始示范。
- 玩家正常行走和跳跃。过了缺口以后可以再按 **T** 收尾；走到最右端也会自然结束示范。小人记住这次示范后留在起点，**回到它身边按 F**，再看它试走；按 T 仍可重新示范。它不会在镜头外自动开始第一次尝试。
- 从缺口左侧起跳、实际落到右侧，能教它跨过缺口。短跳不会被当作成功跨越，也不会凭空给它一座桥。
- 停下来，它会在相应位置停下。暗处前空手 **按住 E**，完成自我安定后再走，才会教它在暗处前先稳住自己。普通停留只会被记成等待。
- 示范时带着灯或玩具进入暗区，它会学着依靠帮助。拿走光后它会停住；恢复实际帮助可以救回这次尝试。也可以召回后重新教。
- **空手 Q** 叫它回到起点，再按 T 示范可以替换教法。示范中 Q 只取消这次示范，不会抹去原来的课程。
- 抵达出口后仍可重试。将报告放回工作台后结果固定。

这不是按时间重放玩家的轨迹。小人会在当前环境里执行学会的方法，仍然受缺口、暗处、风、灯的真实覆盖和玩具发声时限约束。教它跳和自我安定能够创造不用箱、板、灯的路线；教它依赖帮助，在帮助被移走后会遇到真实障碍。原来未示范的 F 试走及 Q 累积走路经验仍然保留。

## 程序接口

`ResearchExpedition` 提供 `IsDemonstrating`、`HasDemonstration`、`Demonstrations`、`DemonstratedActions`、`DemonstrationProgress`、`LearnerHeight`、`HabitPauseRemaining`、`ExecutedHabit`。`LearnerState.Pausing` 使用等待姿态；跳跃保持 Walking，角色根节点有真实高度。

`JourneyChoices.LearnedHabit` 是跨场景只读快照：`Kind`（None / Pause / Jump / SeekHelp）、`PauseSeconds`、`PositionX`、`HelpKind`、`Demonstrations`。它只在小人成功抵达时从实际执行的动作写入，Q 撤销未提交结果，报告提交后不可再召回。多个动作以确实使用的求助、跨缺口跳跃、停顿的顺序选择一个供结尾复现。

记录器最多保存 24 个位置动作。同一位置重复示范会更新动作，单次停顿最多模仿 3 秒，避免长时间离开键盘变成不可恢复的等待。跨缺口必须来自实际接受的跳跃、下降和落地，最高点不会被当成落地。

## 验证

`LearnedHabitChecks.RunChecks()` 包含六组确定性行为检查：真实跳跃与自我安定记录、无工具路线、短跳失败、普通等待不产生勇气、撤除帮助暴露依赖并可重教、取消或过短示范不覆盖原课程。完整 Unity 场景的真实输入与结尾联动由主流程 QA 验证。

## 告别中的兑现

最后一轮成功试走实际采用的习惯会被带到下一代身上。年轻人先回望，再重现同样的停顿、跳跃或等待照应，然后独自走向门。玩家仍可牵回；已经开始的小跳会先落地，再停住后续脚步。靠近门口不会截断习惯，进入门槛后人物经过门框遮挡并保持消失。

人物离开后保留一秒空场，最后一步仍由玩家向右走出。片尾标题、致谢与重玩提示分开出现，按键提示显示时才开放重玩；不以解释成长的文字代替动作。
