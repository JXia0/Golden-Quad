## 仍是 Unity 占位图的槽位

- `deco_blocks`：幼儿园积木障碍。
- `prop_stage_marker`：舞台呼吸点与路线标记；可以继续使用 Unity 色块，不一定需要美术。
- `fx_stage_spotlight`：聚光灯；建议直接用 Unity 2D Light 或渐变材质制作。

最终长廊的三张 `memory_*` 目前复用已有背景。研究背景是 3400×550 的细长图，放进 14×5.5 的回忆窗口后会留下较大空白，调整最终长廊排版时应单独处理。
