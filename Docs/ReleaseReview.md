# 提交前产品复核 · 9 月 6 日

## 这次交付要成立的体验

玩家先得到父母的帮助，再决定怎样帮助另一个人。成长从取回玩具、接受另一个声音、搭出能站住的桥，延伸到示范一种办法；最后，学过的动作在告别时由下一代自己做出来。

- 幼儿园保留来回滚玩具，也允许玩家让开位置、空手等待，亲眼看见孩子自己取回玩具；随后孩子能自行跟随，走太远会停下，回来可以接续。这次经历被保留。
- 孩子按玩家实际示范的力度与停顿回球。用力、轻滚和停下来再放手会得到不同运动结果；完成后仍可自愿再玩，离开后保留进度。
- 舞台能把两拍交给观众。等待、短音鼓励、长音合唱和接回领唱，产生不同的实际发声与节奏；最后需要玩家主动谢幕。告别采用真正演出过的节奏。
- 交接完成后，玩家退开会听到观众自行继续，原来接唱的人开始领唱。谢幕不取消这段回应，离场也无需等它播完。
- 第二段 interlude 可以移动、折叠、托住纸片并反复试走。缺口和失去支撑会让试走停下，召回后布局保留；独立搭成的桥会让下一幕的折叠板出现在工作台旁。
- 研究室记录玩家真正示范的跳跃、自我安定或依靠道具。可以撤掉帮助、观察失败、召回并重新教；提交成功试走后，告别中的年轻人重复这次学会的动作。

这些结果来自玩家的操作。父母带路、侧幕扶肩、松手后等待使用对应交付动作；幼儿园最后由玩家把得到的帮助交给同伴。

## 这轮主动发现并修正的问题

幼儿园等待提示原来没有说明玩家挡住玩具、离得太远或仍在移动，照着文字站着等也可能不发生动作。提示现按真实阻塞原因给出让开、回来、松手或停步。

舞台等待接唱的光斑在暖色背景中不够明显，已让美术呈现任务增强对应观众的等待和发声反馈。E/F 原图的烟雾占比使内联图标过小，现按字号预留更宽空间并放大完整图片；原始提示文本保留，精确清除提示的程序逻辑仍成立。

两个 interlude 原来没有音频播放组件，已补运行时音频安装并验证从前幕进入后会播放旅程曲。新主旋律用于开始画面，幼儿园仍使用自己的配乐。暂停保留实际游戏、牵手与纸桥状态；在暂停时松开 E，会在恢复后正确影响世界。

结束画面采用交付的“结束界面.png”。玩家完成最后一步后渐显整张图，撤下原大标题和感谢文字，留出停顿后才出现小的重玩提示。图不会自动跳走，提前按 Enter 不会跳过。

实际截图复查进一步去掉了舞台出口的半透明原型矩形，补齐右幕外的楼座画面；最终走廊撤下悬空的问号与证据卡，保留铺满房间的背景，并摆回完成的报告、工作台和先前选用的工具。报告压平贴住画中的桌面。暂停图缩小并压低金色亮度，透明外缘直接衔接纯黑底，撤掉造成矩形边的整块叠色。

开场旁白已接入用户交付的 `Voice/vo_prologue`，等待 Start 退去后播放。FinalWalk 最后一步与结束图之间已接入用户交付的 30 秒 `Ending/flashback` 影片。用户确认影片尚未混入旁白，程序在影片实际播放至 0.5 秒时叠加原始 `vo_flashback.wav`，期间降低影片音乐，旁白结束后恢复；影片完整结束后清理两条音源并进入结束图。无片仍立即跳过。录音正文及全流程配音清单见 `Docs/VoiceRecordingScript.md`。

## 按产品负责人的标准回答

| 问题 | 这次判断 |
| --- | --- |
| 我愿意试玩吗？ | 会。最明确的吸引力是能亲手试出“我是否帮得太多”，再改变自己的做法。 |
| 我愿意玩到结尾吗？ | 会。几幕的决定开始有递进，研究中教过的动作会在告别时被认出来，结束图也承担了最后的停留。 |
| 我愿意买单吗？ | 作为一款短篇叙事游戏，我会考虑小额付费。开发自测仍不足以给出确定的购买推荐，需要陌生玩家验证操作是否能被自然理解。 |
| 可能得奖吗？ | 有值得现场展示的竞争点：示范、依赖、改教与告别形成一条可操作的主题线。不能由代码或测试数量推断一定晋级、得奖。 |
| 贴合 grow 吗？ | 贴合。成长表现为主动尝试、接受别人的声音、学会方法，以及帮助撤下之后还能继续。 |
