# 《放开我的手》试玩说明

解压整个文件夹，运行 `LetGo.exe`。请保留旁边的 `LetGo_Data` 与 DLL 文件。

## 操作

- A / D 或方向键：行走；空格：跳跃。
- 按住 E：牵手、拿物件，或空手时稳定呼吸；松开 E：放手、放下物件或发声。
- F：使用附近机关、启动试走、提交后的继续操作；以画面当前短提示为准。
- 研究室 T：开始或结束亲身示范。示范后回到小人身边，按 F 看它试走。
- 研究室空手 Q：召回小人。示范中 Q 取消这次示范；报告放回工作台前都能重做。
- 研究室 H：展开或收起解法提示。
- 舞台 Q：改写两拍；F：让观众接唱，接唱后再按 F 谢幕。
- 片尾 Enter：重新开始。

## 想看“学会你的习惯”时

先进入实验区并拉开内侧门闩。从小人旁按 T，亲自跳过缺口，带灯走入暗处，再按 T 结束。把灯带走，回到小人旁按 F：它学会了跳，却仍会等灯光。

空手 Q 叫它回来，重新按 T 示范。这次跳过缺口后，在暗处前空手按住 E，完成一次稳定呼吸，再结束示范。回到它身边按 F，看它靠自己走过去。

这是可选的解法；箱子、折叠板、牵手和灯的办法仍然有效。成功抵达后可继续试验，把报告放回工作台才固定这一轮结果。最后的告别会回应成功那一轮实际使用的习惯。

幼儿园使用连续行走镜头。最终回忆长廊的黑幕是可穿过的空间，继续向右会走入下一段，往左也可以回去。
