# Letting Go · 放开我的手 — 玩家 README

## 运行环境

- Windows 10 / 11，64 位，使用键盘。
- 开始与暂停菜单也支持鼠标点击。
- 无需安装 Unity；游戏资源和视频均随包提供，游玩不需要联网。
- 本次为 Windows 版本，不是网页版、macOS 或手机版。

## 启动方式

1. 将 ZIP **完整解压**到文件夹，不要直接在压缩软件内运行。
2. 双击 LetGo.exe，保留同目录 LetGo_Data、UnityPlayer.dll、其他 DLL 与数据文件。
3. 点击 START 或按 Enter / Space 开始。

## 必要操作

| 按键 | 用途 |
| --- | --- |
| A / D 或方向键 | 行走；部分互动中选择方向或纸片 |
| Space | 跳跃；纸桥互动中展平或折出桥脚 |
| 按住 E | 牵手、拿起或托住物件，或空手稳定呼吸 |
| 松开 E | 放手、放下、滚出玩具或发声，以当前情境为准 |
| F | 使用附近物件、开始试走、交接、谢幕和继续 |
| Q | 舞台改写；纸桥或研究室召回试走 |
| T | 在研究小人身边开始或结束动作示范；录制时 Q 取消 |
| H | 展开或收起研究室提示 |
| Esc | 暂停与继续；暂停菜单可返回主菜单 |
| Enter | 结尾出现重玩提示后重新开始 |

留意画面中的按键图标。最后小孩会重现学到的动作，在门前回望；可以重新牵住，再松手。它进入门后，最后一步由你迈出。之后播放约 30 秒回忆短片和旁白，再停留在结束照片。

运行包的详细说明为 试玩说明.txt，素材说明为 ASSET_SOURCES.md，字体许可在 Licenses/NotoSerifSC。源工程对应说明位于 Docs 与 Assets/Resources/Fonts。

## English quick start

Windows 10/11 (64-bit), keyboard required. Extract the complete ZIP and run LetGo.exe. Keep all files and folders together. No Unity installation or internet connection is required to play.

Move: A/D or arrow keys. Jump: Space. Hold E to connect, carry or breathe; release E to let go. F interacts. Q rewrites or recalls a trial. T starts/ends a demonstration in the research chapter. Esc pauses. Follow contextual prompts for chapter-specific actions.
